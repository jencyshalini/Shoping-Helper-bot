
# 🛒 Shopping Helper BOT

🚀 An RPA-based Shopping Assistant Bot developed using **UiPath** to automate product extraction, filtering, and email delivery for online shopping assistance.

This bot extracts product details from Flipkart, filters products based on user-defined price range, and sends the filtered results directly to the user's email in an Excel file.

---

# 📌 Project Overview

The Shopping Helper BOT is designed to simplify the online shopping experience by automating product search and filtering processes.

The bot:
- Extracts iPhone product details from Flipkart
- Filters products based on user budget
- Generates an Excel report
- Sends the filtered product list via email

This project demonstrates the practical use of **Robotic Process Automation (RPA)** for e-commerce automation and data handling.

# ⚙️ Workflow

## 1️⃣ Product Search
- Opens Flipkart website
- Searches for iPhone products automatically

## 2️⃣ Data Extraction
- Extracts product details such as:
  - Product Name
  - Price
  - Additional Details

## 3️⃣ User Input
- Accepts:
  - Minimum Price
  - Maximum Price
  - Email Address

## 4️⃣ Data Filtering
- Filters extracted products based on the user's budget range

## 5️⃣ Excel Report Generation
- Saves filtered product details into an Excel file

## 6️⃣ Email Automation
- Sends the Excel report directly to the user's email
